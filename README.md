# Meus Projetos em Python

Repositório de estudos em Python, reunindo exercícios, desafios e projetos práticos organizados por etapas de aprendizado.

O objetivo é documentar meu processo de aprendizagem, praticar conceitos de programação e acompanhar minha evolução no desenvolvimento de soluções utilizando Python.

## Organização do Repositório

* **01-fundamentos:** exercícios introdutórios para praticar os conceitos básicos da linguagem.
* **02-logica-de-programacao:** atividades envolvendo operações, condições e resolução de problemas.
* **03-aplicacoes-basicas:** programas que combinam diferentes conceitos e funcionalidades.
* **04-projetos-intermediarios:** projetos que exigem maior organização e aplicação de recursos da linguagem.
* **05-projetos-avancados:** projetos mais completos, desenvolvidos conforme minha evolução.

## Tecnologias

* Python
* Git
* GitHub

## Objetivo

Construir uma base sólida em programação por meio da prática contínua e do desenvolvimento gradual de projetos.
