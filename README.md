# Meus Projetos em Python

Repositório de estudos em Python, reunindo exercícios, desafios e projetos práticos organizados por nível de dificuldade, com o objetivo de documentar meu aprendizado e acompanhar minha evolução contínua na programação.

## Organização

* `01-fundamentos`: exercícios básicos de Python.
* `02-intermediario`: projetos com conceitos mais avançados.
* `03-avancando`: projetos mais completos e desafiadores.

## Tecnologias

* Python
