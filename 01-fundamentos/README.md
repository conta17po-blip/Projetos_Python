# 🐍 Fundamentos de Python

Esta seção reúne meus primeiros exercícios e práticas em Python, com foco na construção de uma base sólida em lógica de programação e nos conceitos essenciais da linguagem.

## 📚 Conteúdos praticados

- Variáveis e tipos de dados
- Entrada e saída de informações
- Operadores aritméticos e lógicos
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição
- Manipulação básica de dados

## 🎯 Objetivo

Desenvolver o raciocínio lógico, consolidar os fundamentos da programação e documentar minha evolução prática com Python.

## 📈 Progresso

Os exercícios estão organizados para acompanhar minha jornada de aprendizado, desde os conceitos iniciais até desafios que exigem maior aplicação da lógica.
